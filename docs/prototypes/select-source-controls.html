JP Card Watcher · UI proposal

Three ways to hold selection and source

Two controls need a home. Select all / none is currently a link buried in the legend sentence, where it reads as prose rather than a button. And there is no way to see only Cardmarket or only CardTrader rows — both feeds are merged into every table. Each option below is live: click the source filter, tick cards, watch the ↻ CM count follow. Nothing in the real site has changed yet.

Preview at
A

Control strip

A dedicated bar under the header holds everything that decides what a refresh costs: source on the left, selection and ↻ CM on the right. The header goes back to being identity and status only.

Where it lives
New full-width row between header and grid. Segmented Both / CT / CM, then Select all · Clear, then ⚿ and ↻ CM.
Good for
The controls sit next to the button they affect, and the live “n of 3 selected” readout sits between them, so cost is legible before you press.
Costs
~34px of vertical space above the grid, on every screen. On a phone the strip wraps to two lines.
B

Header pills

No new furniture. Both controls become pills in the existing header, styled like the ↻ CM button already there — the cheapest change in both code and screen space.

Where it lives
Inside the sticky header. Show: Both / CT / CM, then ☑ All · ☐ None beside ⚿ and ↻ CM.
Good for
Zero vertical cost, and the header is sticky — the filter stays reachable while you scroll a long grid. Smallest diff to ship.
Costs
Seven controls in one header. Below roughly 1100px it wraps to two or three rows, and a sticky header that tall eats real estate on every scroll; the selected count survives only in the ↻ CM label.
C

Spend bar

Split the two by consequence. Source filtering is free, so it shrinks to a dropdown in the header. Selection spends credits, so it gets a tinted band that states the bill — 2 of 3 cards · ~2 credits — right beside the button that pays it.

Where it lives
Dropdown in the header; violet band above the grid with All · None · Invert and ↻ CM.
Good for
The one irreversible action on the page reads as its own zone, with the credit estimate attached. Invert makes “everything except these two” a single click.
Costs
Most new CSS, and a band that is always on screen even when nothing is selected. A dropdown takes two taps where a segment takes one.

Picking between them

My pick is A. Selection and source both change what the ↻ CM button will do, so they belong in one place next to it, and the strip has room for the “n of 3 selected” readout that the header cannot fit. If header space on phones is the priority, B is the cheaper answer; C is worth it only if you want the credit estimate on screen permanently.

Whichever you pick, the same three things land in the real code: source state and picks stay in localStorage alongside the existing cm-picks, filtering happens in render.js before offers are merged, and the legend keeps its prose but loses its link.
